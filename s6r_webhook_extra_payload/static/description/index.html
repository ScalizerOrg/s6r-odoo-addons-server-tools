Scalizer Webhook Extra Payload

s6r_webhook_extra_payload

Add a configurable Python expression to extend native webhook server action payloads

Description

This module adds an "Extra Payload (Python Expression)" field on the native Odoo webhook server action (ir.actions.server, "Send Webhook Notification").

The expression is evaluated in a restricted (safe_eval) context with record, user and env available, and its result, a dict, is merged into the webhook payload alongside the standard _model/_id/_action and the selected Fields.

Lets an administrator send data that is not a field of the triggering record, such as the id of the user who triggered the action, without any code change.

Usage

Add an extra payload to a webhook action

  1. Enable developer mode.
  2. Go to Settings > Technical > Automation > Server Actions.
  3. Open a server action with Action To Do set to Send Webhook Notification.
  4. Fill in Extra Payload with a Python expression returning a dict, e.g. {'user_id': user.id}.

Configuration

No specific configuration required.
