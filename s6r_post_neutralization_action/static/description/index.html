Scalizer Post Neutralization Action

s6r_post_neutralization_action

Run a configurable, ordered list of server actions right after a database neutralization

Description

This module lets an administrator configure an ordered list of server actions (ir.actions.server) to run automatically right after a database neutralization (odoo.sh duplicate/restore, odoo neutralize command).

It patches odoo.modules.neutralize.neutralize_database via a post_load hook: the standard neutralization always runs first and is committed, then the configured post.neutralization.action lines are executed in order.

With no line configured, the module has no effect on the standard neutralization behavior.

Usage

Configure a post-neutralization action

  1. Enable developer mode.
  2. Go to Settings > Technical > Automation > Post Neutralization Actions.
  3. Add a line: pick an existing server action and a sequence to control the execution order.
  4. Uncheck Active to temporarily disable a line without deleting it.

Configuration

No specific configuration required.
